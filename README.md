# Deepwake Arena

Jeu de combat d’arène en vue du dessus, inspiré des combats dark-fantasy (style Deepwoken). Un seul fichier HTML, sans dépendance.

## Lancer

Ouvrir `index.html` dans un navigateur moderne (Chrome, Firefox, Edge…).

## Contrôles

| Touche | Action |
|--------|--------|
| ZQSD / WASD | Se déplacer |
| Clic gauche / J | Attaque légère |
| Clic droit / K | Attaque lourde |
| Shift / L | Esquive (invulnérabilité courte) |
| Espace / ; | Blocage (maintenir) / Parade (appuyer juste avant l’impact) |
| E / F | Mantra (projectile, cooldown) |
| Échap | Pause |

## Objectif

Survivez **5 vagues**. Entre chaque vague, choisissez 1 amélioration sur 3. La parade au bon moment étourdit l’ennemi et inflige des dégâts de posture.

## Astuce

Les ennemis télégraphient leurs coups (arc rouge / ligne de visée) — c’est le moment de parer.
